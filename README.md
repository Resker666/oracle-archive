# 问机算卜 · 卦象集录

一个受《绝区零》算卦场景启发的本地网页原型。可以摇动龟壳抽取卦象、查看解读，并逐步收集 26 种卦象。

本项目为非官方同人练习，不隶属于米哈游；项目不包含官方游戏素材，也不需要联网或第三方依赖。

## 本地运行

直接用浏览器打开 `index.html` 即可。

如果浏览器限制本地文件的存储功能，可在项目目录启动一个临时静态服务器：

```powershell
python -m http.server 8000
```

然后访问 <http://localhost:8000>。结束服务时，在终端按 `Ctrl+C`。

## 操作

- 选择“开始占卜”，按住并拖动龟壳，或点击“摇动龟壳”推进进度。
- 卦象出现后可查看解读；选择“确认”会将卦象加入集录。
- 在“卦象集录”中按运势分类查看收集进度和已解锁的卦象。
- 集录页的“清空本地记录”会清除本机保存的收集进度。

## 数据与隐私

收集进度和最近记录保存在当前浏览器的 `localStorage` 中，不会上传到服务器。清除浏览器网站数据或更换浏览器后，记录可能无法保留。

## 文件结构

```text
index.html   页面结构与内嵌图形
styles.css   页面样式、布局和动画
app.js       抽签交互、卦象内容与本地记录
```

项目没有构建步骤。修改文件后刷新页面即可查看变化。

# 日常抽取档案

一个受《绝区零》日常活动启发的本地网页。可以在随便观占卜，在六分街或光映广场刮卡，也可以去吼吼饼铺拆零食盲盒。

本项目为非官方同人练习，不隶属于米哈游；项目不包含官方游戏素材，也不需要联网或第三方依赖。

## 本地运行

直接用浏览器打开 `index.html` 即可。

如果浏览器限制本地文件的存储功能，可在项目目录启动一个临时静态服务器：

```powershell
python -m http.server 8000
```

然后访问 <http://localhost:8000>。结束服务时，在终端按 `Ctrl+C`。

## 操作

- **随便观**。拖动龟壳或点击“摇动龟壳”推进进度。自由试玩时，点击“确认”将本次卦象加入集录。集录有 26 种卦象，按运势分类。
- **报刊亭**。拖动刮开约 40% 的票面，或点击“直接揭晓”。两个报刊亭共用一个奖池，开奖记录保留各自的地点。
- **吼吼饼铺**。拆盒获得一张数据卡片和对应奖励，可在数据卡册中查看收集进度。
- **抽取模式**。默认自由试玩。切到日常模式后，所有地点共用每天一次机会，按设备本地日期刷新。日常模式开奖时即保存结果，可在首页或其他地点查看今日结果。

刮刮卡和盲盒的奖品及权重采用本地模拟设定。首页的“查看档案”可按地点筛选最近 40 次开奖记录。

## 数据与隐私

抽取模式、收集进度、最近记录和每日结果保存在当前浏览器的 `localStorage` 中。使用同一浏览器与同一页面地址时，旧版卦象集录会自动迁入。集录页的“清空卦象记录”作用于卦象集录和卦象历史。

## 文件结构

```text
index.html     页面结构与内嵌图形
styles.css     占卜样式、布局和动画
activities.css 地点列表、刮卡、拆盒和档案样式
app.js         页面导航、开奖与档案展示
scenes.js      地点、奖池和抽取权重
divination.js  卦象、摇卦交互和集录界面
scratch.js     票面与刮开面积计算
storage.js     本地存档、迁移和每日次数
```

项目没有构建步骤。修改文件后刷新页面即可查看变化。
